Review my latest game in depth.

1. `uv run chess-coach review --last` for the critical positions.
2. Pull the full move list for that game from `move_evals` so you can see the
   shape of the whole game, not only the flagged moves.
3. Walk me through it:
   - How the opening went, and whether I left theory early (check the Lichess
     Opening Explorer for the actual position before claiming anything about
     theory — see `docs/references.md`).
   - The turning point. There is usually one move where the game was decided;
     the engine numbers will show it as the largest single win-chance drop.
   - What I should have been thinking about at that moment, tied to a named
     concept rather than general advice.
   - Anything I did well. Engine-confirmed only.

Do not narrate every move. I was there.
